# CodeMate AI

面向 Java 初学者的 AI 编程学习平台 MVP，参赛方向为“AI 教育与学习平台”。项目强调可解释反馈、学习闭环与安全边界：导师帮助学生理解，诊断和判题不在服务器执行用户代码。

> 交付状态：可本地运行、可直接演示、可开源。默认无需 API 密钥即可体验全部核心流程。

## 核心功能

- **动态产品欢迎页**：以交互式 AI 导师、代码诊断和学习路径演示呈现产品价值，支持响应鼠标的萤火光点、功能切换、移动端适配，并可一键进入学习空间或从工作台返回介绍页。
- **清晰的中文学习工作台**：响应式布局，支持桌面与移动端。
- **个性化学习档案**：首次进入可填写昵称、Java 学习阶段、目标和每日题量；首页推荐与 AI 讲解会随档案调整，并支持“仅重置档案”或“清除全部本地数据”。
- **AI 编程导师**：支持 OpenAI 兼容的 Chat Completions API；请求期间显示旋转星光思考状态，回答以逐字打印方式呈现；没有密钥时进入明确标识的演示模式。
- **代码诊断**：检查缺失分号、括号不匹配、字符串比较、疑似无限循环、数组长度误用、敏感信息输出等常见问题。
- **结构化 Java 题库**：内置 32 道题，覆盖 16 个从入门到进阶的知识领域；选择题精确判题，代码题用可解释的静态结构规则检查，不执行提交的 Java 代码。
- **错题记录**：错误答案自动加入错题本，答对后自动移除。
- **学习画像**：记录练习次数、正确率、掌握知识点与诊断次数。
- **个性化学习报告**：展示 16 类知识掌握度、强项与薄弱点、最近 7 天表现和下一步学习建议。
- **AI 学习总结**：把匿名汇总后的学习阶段、得分和知识点表现交给模型，生成未来 7 天学习计划；不上传昵称、答案内容或代码。
- **每日自适应练习**：按学习阶段、历史薄弱点和每日目标选出 2/4/6 道题，同一天保持稳定、隔天自动轮换，也可查看全部题库。
- **个性化推荐**：根据 16 个知识领域的历史得分推荐最薄弱的学习内容。
- **轻量课程检索**：16 张原创课程卡片覆盖变量、流程控制、面向对象、异常、集合、泛型、IO 与 Lambda；导师回答可显示引用来源。
- **免费课程拓展**：每张知识卡均提供中国大学MOOC高校课程官方入口和对应练习；项目不存储或转载第三方视频。

学习档案和学习记录仅保存在当前浏览器的 `localStorage` 中，不需要密码，也不上传个人信息。

## 技术架构

```text
浏览器（HTML / CSS / JavaScript）
   ├─ 学习工作台、导师对话、诊断、题库、错题本、画像
   └─ localStorage：本地学习档案与个人学习记录
                 │ HTTP / JSON
Node.js 原生 HTTP 服务（零第三方运行依赖）
   ├─ AI 适配层：OpenAI 兼容 API / 演示模式
   ├─ Java 静态诊断规则
   ├─ 安全静态判题规则
   └─ 课程关键词检索
```

采用零第三方依赖的单体结构是本次限时 MVP 的主动取舍：下载后只需 Node.js 即可运行，便于评委复现，也减少部署故障点。

## 环境要求

- Node.js 18 或更高版本（需要内置 `fetch`）
- 不需要安装 JDK，因为服务端不会编译或执行用户代码
- 本项目没有第三方 npm 依赖；依赖清单见 `package.json`

## 安装与运行

```bash
git clone <你的仓库地址>
cd codemate-ai
node server.js
```

访问 <http://127.0.0.1:3000>。

如果本机提供 npm，也可运行：

```bash
npm start
```

### 配置真实模型（可选，推荐比赛演示时启用）

复制 `.env.example` 为 `.env`，然后根据所用平台填写。项目本身不会自动读取 `.env` 文件，以保持零依赖；启动前请通过系统或部署平台注入环境变量。

PowerShell 示例：

```powershell
$env:AI_API_KEY="你的密钥"
$env:AI_BASE_URL="https://api.openai.com/v1"
$env:AI_MODEL="gpt-4o-mini"
$env:AI_MAX_TOKENS="700"
node server.js
```

使用 DeepSeek 时可改为：

```powershell
$env:AI_API_KEY="你的 DeepSeek 密钥"
$env:AI_BASE_URL="https://api.deepseek.com"
$env:AI_MODEL="deepseek-flash"
$env:AI_MAX_TOKENS="700"
node server.js
```

环境变量：

| 名称 | 必填 | 默认值 | 说明 |
|---|---:|---|---|
| `AI_API_KEY` | 否 | 空 | 留空时使用演示模式 |
| `AI_BASE_URL` | 否 | `https://api.openai.com/v1` | OpenAI 兼容 API 根地址 |
| `AI_MODEL` | 否 | `gpt-4o-mini` | 模型名称 |
| `AI_MAX_TOKENS` | 否 | `700` | 单次回答最大输出量；程序强制限制在 200–1200 之间 |
| `HOST` | 否 | `127.0.0.1` | 监听地址；部署时可设为 `0.0.0.0` |
| `PORT` | 否 | `3000` | 服务端口 |

不要提交 `.env`、真实密钥、个人信息或聊天日志；`.env` 已加入 `.gitignore`。

### Cloudflare Workers 配置

仓库中的 `wrangler.jsonc` 已设置 DeepSeek 接口地址、模型名和单次输出上限。线上部署时只需在 Cloudflare 项目的 **Settings → Variables and Secrets** 中添加加密变量 `AI_API_KEY`，值为 DeepSeek 平台创建的密钥，然后重新部署。不要把密钥写入 `wrangler.jsonc` 或上传到 GitHub。

### 国内网络备用部署（腾讯云 CloudBase Run）

仓库已提供 `Dockerfile`，可直接部署到腾讯云 CloudBase Run，作为国内网络可访问的比赛备用地址：

1. 在腾讯云 CloudBase 控制台创建环境并进入“云托管”。
2. 创建服务，选择“代码部署”或关联当前 GitHub 仓库。
3. 构建方式选择仓库中的 `Dockerfile`，服务端口填写 `8080`。
4. 在环境变量中添加 `AI_API_KEY`、`AI_BASE_URL=https://api.deepseek.com`、`AI_MODEL=deepseek-flash`、`AI_MAX_TOKENS=700`。
5. 部署成功后，打开服务分配的默认公网域名，并用国内普通网络测试首页与 AI 导师。

默认域名适合作为比赛测试和备用入口；长期正式运营建议绑定已备案的自定义域名。API 密钥只能填写在云平台环境变量中，不得写入代码或 GitHub。

## 推荐演示流程（约 3 分钟）

1. 打开动态欢迎页，切换 AI 导师、代码诊断和学习路径演示，点击“立即体验”进入学习空间，再介绍学习画像、今日目标与薄弱点推荐。
2. 进入“题库练习”，介绍按阶段与薄弱点生成的“今日推荐”，再故意答错一道题，展示即时解析与自动进入错题本。
3. 完成一道代码题，说明服务器只检查关键结构，不执行不受信任代码。
4. 在“代码诊断”使用默认示例，展示缺少分号与字符串比较建议。
5. 在“AI 编程导师”询问“数组下标为什么从 0 开始？”，展示真实 AI 与课程引用。
6. 打开“课程知识库”，展示知识卡、相关练习和高校免费课程入口。
7. 打开“学习报告”，展示 16 类知识掌握度、近期数据，并生成 AI 学习总结。

如已配置模型 API，第 5 步会自动切换到真实 AI，顶部状态会显示模型名。

## API 概览

| 方法 | 路径 | 功能 |
|---|---|---|
| `GET` | `/api/status` | 服务状态与 AI 模式 |
| `GET` | `/api/lessons` | 课程卡片 |
| `GET` | `/api/exercises` | 去除答案后的题目列表 |
| `GET` | `/api/search?q=` | 轻量课程检索 |
| `POST` | `/api/tutor` | AI/演示导师回答 |
| `POST` | `/api/report` | 根据匿名学习汇总生成 AI/演示学习总结 |
| `POST` | `/api/diagnose` | Java 静态规则诊断 |
| `POST` | `/api/judge` | 选择题或代码结构判题 |

## 安全设计

- 后端从不调用 `javac`、`java`、shell 或容器来执行用户代码。
- 请求体上限为 200 KB，导师消息和诊断代码会进一步限制长度。
- 前端显示用户内容时执行 HTML 转义。
- API 密钥只从服务端环境变量读取，不下发到浏览器。
- 导师会携带学习阶段、学习目标和最多 3 个薄弱知识点，但不会上传昵称等不必要的个人信息。
- AI 学习报告只上传阶段、目标、得分和知识点汇总，不上传昵称、原始答案或用户代码。
- 导师消息最多读取 3000 个字符，单次回答默认最多 700 tokens，用于控制费用与异常超长输出。
- 真实模型不可用时显示错误并提供演示模式回答，不伪装为真实 AI 成功。

## 已知限制与后续扩展

- **代码判题不是在线编译器**：静态规则可解释且安全，但不能证明代码一定能编译或覆盖全部边界情况。后续可接入独立、限时、限资源、禁网的沙箱判题服务。
- **代码诊断是启发式规则**：可能误报或漏报，不能替代编译器、单元测试和专业静态分析器。
- **课程检索是轻量文本匹配**：当前已真实实现并可展示引用来源，但不是向量数据库式 RAG。后续可加入课程文档切片、Embedding、重排与来源页码。
- **学习档案仅单机保存**：当前“登录”是无需密码的本地档案，不是服务器账号；没有云同步和多端同步。后续可增加匿名账户与可导出的学习记录。
- **内容仍是内置数据**：当前内置 32 道结构化题目和 16 张原创知识卡片，已经覆盖 Java 学习主干，但不是“全部 Java 资料”。后续可增加后台题库、课程文档导入、版本管理与内容审核流程。
- **AI 输出可能不准确**：真实模型回答仍需用户结合编译器和官方文档验证。
